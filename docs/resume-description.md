# QuantOS — Resume Description

QuantOS is a full-stack quantitative trading platform featuring:
- **Authentication & JWT security** for access-controlled API endpoints.
- **Modular backend architecture** with FastAPI route modules for engines and analytics.
- **Interactive dashboard UI** built with React and TypeScript.

Key contributions:
- Implemented authentication flow (register/login/logout), token-based session persistence, and protected frontend routing.
- Built UI/UX improvements including loading, empty, error, and success states.
- Ensured consistent API integration between frontend services and backend routes.

Tech stack:
- Backend: FastAPI, SQLAlchemy
- Security: JWT
- Frontend: React, TypeScript, Vite
